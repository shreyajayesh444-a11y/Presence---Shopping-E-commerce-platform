# PRÉSENCE

PRÉSENCE is a spatial commerce platform designed for luxury fashion retail.

It explores how AI, Augmented Reality, personalization and Human–Computer Interaction can reduce uncertainty during online fashion shopping.

## Core Journey

Discover → Browse → Explore → Understand → Experience → Compare → Decide → Purchase

## Core Features

- Luxury fashion discovery and search
- AI Size Recommendation
- Occasion Intelligence
- Material Viewer
- AI Stylist — Sofia
- Smart Compare
- Spatial AR experience
- Spatial product comparison
- Complete the Look
- Wishlist
- Bag and checkout flow
- Adaptive personalization
- Style Profile
